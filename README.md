# EHR-Governance-Project

EHR Risk & Governance Implementation Project (ISO 27001 + COBIT + ITIL)

A full risk-governed EHR system implementation for a mid-level healthcare provider in the UAE

This project demonstrates how to implement a secure, compliant, and well-governed Electronic Health Record (EHR) system using a combination of ISO 27001, COBIT 2019, and ITIL 4 frameworks.
It is designed to showcase real-world skills in IT risk management, governance, cybersecurity, and service operations — especially relevant for junior and mid-level IT Risk & Governance roles.

* Project Objective

To design and implement a full governance and security model for an EHR platform in a UAE hospital, prioritizing:

Protection of Protected Health Information (PHI)

Alignment with UAE healthcare regulatory requirements

Reduction of cybersecurity and operational risks

Establishment of strong decision-making and service management processes

Ensuring EHR availability, integrity, and confidentiality

🏥 Scenario Overview

A mid-sized UAE hospital is deploying a modern EHR solution.
My role was to design a complete risk-governed implementation approach, including:

Governance structure

ISMS scope

Risk assessment & treatment

ITIL process documentation

SOPs

Dashboards & reporting

Training materials

Executive documentation

This simulates the responsibilities of an IT Risk Analyst / Governance Analyst / Cybersecurity Analyst working in healthcare.
